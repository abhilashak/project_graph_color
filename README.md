My project in web application field , The graph colouring algorithm
------

# About

Today the web applications have a great value. Anyone can access the application and do their jobs through the web. 
Hosting the application require a server, that manages the request and stores the data. 
Here the google appengine does the job. Google app engine is a cloud environment that provides the server-side services we want. 
Here the application is a graph colouring technique which takes a graph. 
This provides a proper colour to each of the nodes according to the vertex colouring algorithm. 
The algorithm is implemented in python.

The front end of the project is a HTML5 page. It uses the web application languages javascript and jquery. 
Here the front-end consists of a html5 canvas and the control buttons. We can draw an undirected graph in the canvas using the control buttons. 
These buttons are created in html5 page. The program code resides in two files. One html5 file and one javascript file.

# Technologies Used
1. HTML5
2. Python
3. Javascript / JQuery
4. Google App Engine
